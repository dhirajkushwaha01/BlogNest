# BlogNest

A full-stack blogging application built with Node.js, Express, MongoDB and EJS.

## Features
- User signup, signin and logout
- JWT authentication using cookies
- Create blogs with cover image upload (Multer)
- Home page with blog cards
- Single blog page with author details
- Comment system for logged-in users

## Tech Stack
Node.js, Express.js, MongoDB (Mongoose), EJS, Bootstrap 5, JWT, Multer
